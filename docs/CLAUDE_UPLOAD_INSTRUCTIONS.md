# Upload instructions for Claude or GitHub

This ZIP is a complete initial file set for the currently empty `vbvbbv150/studio` repository.

1. Extract the ZIP locally or in an environment that can access the repository.
2. Copy the contents of the `studio-foundation-v0.1.0/` folder into the repository root. Do not create an extra nested folder named `studio-foundation-v0.1.0`.
3. Preserve the exact directory paths.
4. Do not rewrite, refactor, or redesign the files during upload.
5. Create one commit on a new branch named `foundation/initial-studio-shell` (preferred) or on `main` only if branch creation is unavailable and the owner explicitly approves.
6. After upload, report the commit SHA and list of files. Do not claim a build passed unless `npm install` and `npm run build` were actually run.
7. Do not add secrets, API keys, personal data, or private credentials.

Important: the app is an early shell. Local drafts are browser-memory only; GitHub import, real runtime, and AI generation are not connected yet.
